# AI Resume Shortener v1.0.0 Release Notes

**AI Resume Shortener v1.0.0** is the initial production release of the enterprise-grade recruitment intelligence and resume evaluation platform for **Frappe HR / ERPNext**.

---

### Added

- **Multi-Model AI Orchestration**: Dynamic support for **Google Gemini**, **OpenRouter**, **Claude**, and **OpenAI** with automatic provider failover and token cost matrix tracking (input/output cost per 1M tokens).
- **ATS Fit Scoring & Star Rating**: Automated calculation of Fit Score (0–100), Match %, Skills, Experience, and Education breakdowns with automatic mapping to Frappe HR Candidate Star Ratings (1 to 5 stars).
- **Enterprise Prompt Versioning**: Created `Ai Prompt Version` DocType to manage versioned prompt templates (`v1.0-default`, `v2.0-custom`) with one-click activation and audit logging.
- **Centralized Audit Logging**: Created `Ai Analysis Log` DocType recording execution status (`Queued`, `Success`, `Failed`, `Retried`), latency, token usage, USD costs, and raw JSON payloads.
- **Candidate Evaluation History**: Integrated `Job Applicant AI History` child table on `Job Applicant` for complete auditability over time.
- **Desk Workspace & Actions**: Added **AI Resume Shortener Intelligence Center** Workspace with live Number Cards and Desk action buttons (**Analyze with AI**, **Enqueue Background Job**, **Benchmark Models**).
- **AI Model Benchmarking**: Integrated side-by-side comparative model evaluation tool (`benchmark_resume`).
- **Async Queue & Deduplication Locks**: Per-applicant background job enqueuing on queue `"default"` with queue lock protection against duplicate executions.
